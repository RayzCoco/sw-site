# Simple photography portfolio site for my friend

## Overview

This is a porfolio site for my friend who is into photography. It has a simple webpage design to just showcase pictures he took. It is almost complete but not enough data as the owner would like to add more pictures that is suitable with the design.

## How to start project

1. Initialise project by running `npm install`
2. Run project with `npm run build`
3. Success!

## Technology/ Language used

1. HTML
2. CSS (TailwindCSS)
3. Javascript
4. ReactJS
5. Lazyload.js
